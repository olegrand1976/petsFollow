## Objectif

Piloter l’équipe commerciale : indicateurs, suivi, prospects d’équipe, production personnelle.

## Acteurs

| Rôle | Compte | MDP |
|------|--------|-----|
| Manager | `commercial.manager@petsfollow.test` | `CommercialDemo123!` |

## Prérequis

- Staging Web.
- Seed : manager Bérénice + reps Camille / Alex.

## Étapes

1. Se connecter avec `commercial.manager`.
2. Ouvrir le **tableau de bord équipe**.
3. Vérifier les indicateurs d’équipe.
4. Ouvrir le **suivi** : RDV à venir, prospects stale, **tâches en retard** de l’équipe.
5. **Assigner une relance** (CTA) sur un prospect claimé de l’équipe.
6. Ouvrir l’**agenda équipe** (`/commercial-manager/agenda`) et filtrer par commercial.
7. Consulter les **prospects équipe**.
8. Vérifier l’accès à la **production personnelle** (CRM / encode du manager).

## Résultat attendu

- Dashboard équipe charge.
- Suivi actionnable (overdue + assign).
- Agenda équipe lisible.
- Distinction claire équipe vs portefeuille perso.
- Reps Camille / Alex visibles dans le pilotage.
